# Сторонние компоненты

Все библиотеки поставляются локально в папке `vendor`; во время работы страница не загружает код с CDN.

| Файл | Компонент | Версия | Лицензия |
|---|---|---:|---|
| `jszip.min.js` | JSZip | 3.10.1 | MIT / GPL-3.0 |
| `diff_mat2.js` | diff-match-patch | порт без встроенного номера версии | Apache-2.0 |
| `mammoth.browser.min.js` | Mammoth.js | номер не встроен в данный bundle | BSD-2-Clause |
| `xlsx.full.min.js` | SheetJS Community Edition | 0.20.3 | Apache-2.0 |
| `pdf.min.js`, `pdf.worker.min.js` | PDF.js | 3.11.174 | Apache-2.0 |

Проектные страницы компонентов:

- <https://stuk.github.io/jszip/>
- <https://github.com/google/diff-match-patch>
- <https://github.com/mwilliamson/mammoth.js>
- <https://sheetjs.com/>
- <https://mozilla.github.io/pdf.js/>

Этот файл является перечнем компонентов, а не заменой их полных лицензионных текстов и условий распространения.
